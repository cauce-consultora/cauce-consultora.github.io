# cauce-consultora.github.io
Sitio web de Cauce Consultora

Sitio del trabajo grupal de la materia **Actuación Profesional del Licenciado en Sistemas de Información (APLSI)**. Presenta a Cauce, una consultora en sistemas de información, y su caso de consultoría con Orann, una empresa familiar de alimentos naturales que se prepara para cambiar de manos.

Publicado en: https://cauce-consultora.github.io

## Estructura

| Archivo | Contenido |
|---|---|
| `index.html` | Inicio: propósito, desafíos que abordamos, servicios, metodología, principios, quiénes somos y caso destacado |
| `orann.html` | El proyecto Orann etapa por etapa, con un entregable por etapa |
| `img/logo-cauce.png` y `img/favicon.png` | Logo de la marca e ícono de la pestaña |
| `img/equipo/` | Fotos de los integrantes |

Es un sitio estático (HTML y CSS, sin dependencias), servido por GitHub Pages desde la rama `main`. Cada cambio que se sube a `main` se publica en uno o dos minutos.
